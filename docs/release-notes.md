## BlueGlance 0.1.0

The first release: battery levels of your Bluetooth devices, at a glance.

### Download

| File | For |
|---|---|
| `blueglance_0.1.0_all.deb` | **Ubuntu 24.04+, Debian 13+, Linux Mint 22+, Pop!_OS 24.04+** — `sudo apt install ./blueglance_0.1.0_all.deb` |
| `BlueGlance-0.1.0.flatpak` | Any distro with Flatpak — `flatpak install --user ./BlueGlance-0.1.0.flatpak` |
| `blueglance@rafay-ah.github.io.shell-extension.zip` | The GNOME Shell extension on its own (already included in the .deb) |
| `blueglance-0.1.0.tar.gz` | Source — run `./install.sh` on any distro (Fedora, Arch, openSUSE…) |

After installing on GNOME, **log out and back in once** so the desktop widget extension loads.

### Highlights

- macOS-style desktop widget in small, medium and large sizes, light and dark
- AirPods and Beats: left, right and case battery
- Mice, keyboards, headsets, controllers, Logitech receivers — anything UPower or BlueZ knows
- Low-battery notifications (and optional "fully charged")
- Top bar menu on GNOME, tray icon on KDE Plasma, Cinnamon, XFCE, Budgie…
- Starts at login in the background (toggle in Preferences)
